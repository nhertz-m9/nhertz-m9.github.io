<h1>背景</h1>
<ul>
<li>以下は、クロージャの戻り値に <code>Future</code> を持たせたコードで、これはコンパイルに失敗する。</li>
</ul>
<pre><code class="hljs language-rust"><span class="hljs-keyword">let</span> <span class="hljs-keyword">mut </span><span class="hljs-variable">xs</span> = <span class="hljs-built_in">vec!</span>[];

<span class="hljs-title function_ invoke__">cls</span>(<span class="hljs-number">42</span>).<span class="hljs-keyword">await</span>;
</code></pre>
<pre><code>captured variable cannot escape `FnMut` closure body
`FnMut` closures only have access to their captured variables while they are executing...
...therefore, they cannot allow references to captured variables to escape
</code></pre>
<ul>
<li>
<p><code>cls</code> の返す <code>Future</code> は <code>cls</code> 由来の <code>&#x26;mut xs</code> をキャプチャしているが、従来の <code>call_mut</code> の制約ではこれを表現できなかった。</p>
</li>
<li>
<p>このままでは、<code>Future</code> 生存中に <code>cls</code> が drop した場合、 <code>Future</code> の参照先が消滅してしまう。</p>
</li>
<li>
<p>c.f. <code>FnMut since 1.0.0</code> の実装。</p>
</li>
</ul>
<pre><code class="hljs language-rust"><span class="hljs-keyword">pub</span> <span class="hljs-keyword">trait</span> <span class="hljs-title class_">FnMut</span>&#x3C;Args>: <span class="hljs-built_in">FnOnce</span>&#x3C;Args> {

<li>

</li>
<li>
<p>c.f. <code>AsyncFnMut since 1.85.0</code> の実装。</p>
</li>
</ul>
