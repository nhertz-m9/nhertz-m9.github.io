【Rust】AsyncFnMut を GAT で実装してみる

May 5, 2026

前提条件

  • rustc 1.95.0-nightly

背景

  • 以下は、クロージャの戻り値に Future を持たせたコードで、これはコンパイルに失敗する。
let mut xs = vec![];

let mut cls = |arg| async {
    xs.push(arg);
};
cls(42).await;

captured variable cannot escape `FnMut` closure body
`FnMut` closures only have access to their captured variables while they are executing...
...therefore, they cannot allow references to captured variables to escape

  • cls の返す Future は cls 由来の &mut xs をキャプチャしているが、従来の call_mut の制約ではこれを表現できなかった。

  • このままでは、Future 生存中に cls が drop した場合、 Future の参照先が消滅してしまう。

  • c.f. FnMut since 1.0.0 の実装。

pub trait FnMut<Args>: FnOnce<Args> {

    extern "rust-call" fn call_mut(
        &mut self,
        args: Args,
    ) -> Self::Output;
}

  • この問題を解決するため、Generic Associated Types と呼ばれる型システムの拡張により、クロージャが返す Future が、そのクロージャ自身を借用していることを表現できるようになった。

  • c.f. AsyncFnMut since 1.85.0 の実装。

pub trait AsyncFnMut<Args>: AsyncFnOnce<Args> {

    type CallRefFuture<'a>: Future<Output = Self::Output>
        where Self: 'a;

    extern "rust-call" fn async_call_mut(
        &mut self,
        args: Args,
    ) -> Self::CallRefFuture<'_>;
}

実装

  • 上記のコードに相当する処理を実行するクロージャを GAT を用いて実装していく。
  • 実装にあたり以下の nightly feature を使っている。ただし、後述する方法で回避することもできる。
#![feature(
    impl_trait_in_assoc_type, 
)]

LendingTrait

  • 公式の実装に習い、戻り値の借用期間を考慮した LendingFnMut を実装する。
trait LendingFnMut<Arg> {
    type LendingOutput<'t>
    where
        Self: 't;

    fn call_mut(&mut self, arg: Arg) -> Self::LendingOutput<'_>;
}

impl<'c, Arg> LendingFnMut<Arg> for AnonymousAsyncClosure<'c, Arg> {
    
    type LendingOutput<'t> = impl Future<Output = ()> where Self: 't;

    fn call_mut(&mut self, arg: Arg) -> Self::LendingOutput<'_> {
        async move {
            self.xs.push(arg);
        }
    }
}

  • associated type の定義に impl Trait を用いているが、ここは nightly に依存する。

  • 回避策の一つとして、Pin<Box<dyn Future>> に逃がす方法が考えられるが、この方法では Box による allocation と dynamic dispatch が必要になる。

type LendingOutput<'t> = Pin<Box<dyn Future<Output = ()> + 't>> 
    where Self: 't;

Closure

struct AnonymousAsyncClosure<'c, Arg> {
    xs: &'c mut Vec<Arg>
}

Test

async fn async_block_closure_test() {

    let mut xs = vec![];

    let mut cls = AnonymousAsyncClosure { xs: &mut xs };
    cls.call_mut(42).await;

    println!("{xs:?}");
}
let mut cx = std::task::Context::from_waker(std::task::Waker::noop());
let _ = std::pin::pin!(async_block_closure_test()).poll(&mut cx);
