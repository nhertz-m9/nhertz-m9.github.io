<h1>概要</h1>
<ul>
<li><code>async fn</code> がコンパイルされた結果の匿名ステートマシンを、そのままコルーチンのステートマシンとして利用する。</li>
</ul>
<h2>Yield</h2>
<ul>
<li>
<p><code>pending: true</code> で停止し、 <code>pending: false</code> で進行する <code>Future</code> として実装する。</p>
</li>
<li>
<p>後述する <code>CoroutineContext</code>（タスク側）と <code>Coroutine</code>（制御側）が内部値を <code>Rc</code> で共有できるようにしておく。</p>
</li>
<li>
<p>とりあえずは single-threaded での動作のみを仮定する。</p>
</li>
</ul>

<h2>Coroutine</h2>
<ul>
<li>
<p>タスク外部から <code>resume()</code> によって <code>pending</code> を <code>false</code>（進行）へ変更した後、手動でタスクの poll を進める。</p>
</li>
<li>
<p>今、<code>pending: false</code> であるから、poll されたタスクは前回の <code>r#yield().await</code> を通過し、次の <code>r#yield().await</code> まで進むことができる。</p>
</li>
</ul>

<h1>補足</h1>
<ul>
<li>実際に yield しているのは <code>r#yield()</code> の呼び出し時ではなく、返された Future を <code>.await</code> した時であるため、以下のようなコードを許すと、意図しない挙動となる。</li>
</ul>
<pre><code class="hljs language-rust"><span class="hljs-keyword">let</span> <span class="hljs-variable">a</span> = cc.<span class="hljs-title function_ invoke__">r#yield</span>();

</ul>
