【Rust】Async ステートマシンを利用した手動駆動コルーチン

May 6, 2026

前提条件

  • rustc 1.93.0

概要

  • async fn がコンパイルされた結果の匿名ステートマシンを、そのままコルーチンのステートマシンとして利用する。

実装

Yield

  • pending: true で停止し、 pending: false で進行する Future として実装する。

  • 後述する CoroutineContext（タスク側）と Coroutine（制御側）が内部値を Rc で共有できるようにしておく。

  • とりあえずは single-threaded での動作のみを仮定する。

#[derive(Clone)]
struct Yield {
    pending: Rc<Cell<bool>>,
}

impl Default for Yield {
    fn default() -> Self {
        Self {
            pending: Rc::new(Cell::new(false)),
        }
    }
}

impl Future for Yield {
    type Output = ();

    fn poll(self: Pin<&mut Self>,　cx: &mut Context<'_>) -> Poll<Self::Output> {
        if self.pending.get() {
            Poll::Pending
        } else {
            Poll::Ready(())
        }
    }
}

CoroutineContext

  • タスク内部から r#yield().await によって pending の値を true（停止）へ変更し、Yield を poll する。
struct CoroutineContext {
    yield_state: Yield,
}

impl CoroutineContext {
    fn r#yield(&mut self) -> impl Future<Output = ()> {
        self.yield_state.pending.set(true);
        self.yield_state.clone()
    }
}

Coroutine

  • タスク外部から resume() によって pending を false（進行）へ変更した後、手動でタスクの poll を進める。

  • 今、pending: false であるから、poll されたタスクは前回の r#yield().await を通過し、次の r#yield().await まで進むことができる。

struct Coroutine<F: Future> {
    task: Pin<Box<F>>,
    yield_state: Yield,
}

impl<F: Future> Coroutine<F> {
    fn new<T: FnOnce(CoroutineContext) -> F>(task: T) -> Self {
        let yield_state = Yield::default();

        Self {
            task: Box::pin(task(CoroutineContext {
                yield_state: yield_state.clone(),
            })),
            yield_state,
        }
    }

    fn resume(&mut self) -> CoroutineState {
        let waker = Waker::noop();
        let mut cx = Context::from_waker(waker);

        self.yield_state.pending.set(false);

        match self.task.as_mut().poll(&mut cx) {
            Poll::Ready(_) => CoroutineState::Complete,
            Poll::Pending => CoroutineState::Yielded,
        }
    }
}

CoroutineState

  • タスクの実行が終了したかどうかを resume() の戻り値として外部から確認できるようにする。
#[derive(PartialEq, Eq, Debug)]
enum CoroutineState {
    Yielded,
    Complete,
}

補足

  • 実際に yield しているのは r#yield() の呼び出し時ではなく、返された Future を .await した時であるため、以下のようなコードを許すと、意図しない挙動となる。
let a = cc.r#yield();
let b = cc.r#yield();

a.await;
b.await;
  • そのため、マクロを定義し、cc.r#yield().await の形を強制させる。
macro_rules! r#yield {
    ($cc:ident) => {
        $cc.r#yield().await
    };
}

Test

let label = String::from("#");

let mut coroutine1 = Coroutine::new(async |mut cc| {
    for i in (0..).filter(|i| *i % 2 == 0) {
        println!("{label} {i}");
        r#yield!(cc);
    }
});

let mut coroutine2 = Coroutine::new(async |mut cc| {
    for i in (0..).filter(|i| *i % 2 == 1) {
        println!("{label} {i}");
        r#yield!(cc);
    }
});

coroutine1.resume();
coroutine2.resume();
coroutine1.resume();
coroutine2.resume();
coroutine1.resume();
coroutine2.resume();
