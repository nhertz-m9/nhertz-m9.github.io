【In Falsus】Unity IL2CPP をリバースエンジニアリングする

September 13, 2026
  • c.f. 【In Falsus Demo】Steamworks の初期化をバイパスして起動する

前提条件

  • Il2CppInspectorRedux 2026.2
  • Ghidra 12.1.3

背景

  • 前回は if-app_Data\Managed 以下の DLL を dnSpy で解析した。しかし、今回は Managed ディレクトリが存在せず、該当する DLL はすべて Unity IL2CPP で生成された GameAssembly.dll に集約されている。

  • IL2CPP

CSharp Assembly -> Cpp code -> GameAssembly.dll

  • また、ネイティブコード以外の情報は、infalsus_Data\il2cpp_data\Metadata\global-metadata.dat にメタデータとして存在する。

  • dnSpy で構造を確認することはできないので、Ghidra + Il2CppInspectorRedux を使用して解析する。Il2CppDumper は現在 Metadata v39 に対応していないので却下。

  • Il2CppInspectorRedux で IL2CPP の解析情報を生成し、それを Ghidra へ取り込む。

Il2CppInspectorRedux

global-metadata.dat、GameAssembly.dll を指定し、Ghidra 向けの Disassembler metadata を生成する。

  • 先ほど生成した il2cpp.py は実行に Python 3 を要求するため、Ghidra は ghidraRun.bat ではなく support\pyghidraRun.bat から起動する必要がある。

  • 手順に沿って Auto Analysis を終わらせた後、Symbol Tree Window にて Game.dll::ifapp::Game::StartUpScene::StartUpScene_Start を確認できる。
