<h1>背景</h1>
<ul>
<li>
<p>インストールディレクトリ直下の <code>if-app.exe</code> を直接起動すると、Steam 側に「ゲーム設定が利用できません」とのエラーメッセージが表示され、ゲーム自体は応答なしとなる。</p>
</li>
<li>

<h2>改変例</h2>
<ul>
<li>
<p>上述の <code>$p.$NA()</code> が常に <code>true</code> を返すよう改変してみる。冒頭の <code>if</code> 分岐を通らなければ、そもそも SteamAPI の初期化自体行わないので、条件式 <code>$p.$Af</code> を否定してみる。</p>
</li>
<li>
<p>該当行で右クリックし、<code>Edit IL Instructions</code> を選択。</p>
</li>
</ul>
<pre><code>1 ldsfld bool $b.$p::$Af

<ul>
<li>

</li>
<li>
<p>File -> Save Module から改変した DLL をエクスポートできる。エクスポート後、元の <code>Game.dll</code> を置き換え、<code>if-app.exe</code> を直接起動すると、Steam なしで起動することに成功する。</p>
