【In Falsus Demo】Steamworks の初期化をバイパスして起動する

September 13, 2026

前提条件

  • dnSpy v6.1.8 (.NET)

背景

  • インストールディレクトリ直下の if-app.exe を直接起動すると、Steam 側に「ゲーム設定が利用できません」とのエラーメッセージが表示され、ゲーム自体は応答なしとなる。

  • %USERPROFILE%\AppData\LocalLow\lowiro\if-app\Player.log の末尾を見ると、Unity / DirectX / FMOD 側の初期化処理は正常に完了しており、ゲーム側の初期化処理で終了していることが確認できる。

Starting up. Version:0.3.1
Before ApplicationHelper
[FMOD] InitCore successful
[FMOD] InitCore successful
QuitOrThrow called

  • if-app_Data\Plugins\x86_64\steam_api64.dll、if-app_Data\Managed\com.rlabrecque.steamworks.net.dll が存在する。これは Steamworks.NET を利用する構成である。

  • if-app_Data\Managed 以下の DLL が Steamworks の初期化を行っているのだと考えられるので、とりあえず、Game.dll を dnSpy で解析してみる。

解析

原因箇所の特定

  • ログに出力されていた Before ApplicationHelper を文字列検索してみると、Start() 関数が見つかる。
private void Start()
{
    Debug.unityLogger.Log("Before ApplicationHelper");
    $se.$Nz();

    // extra lines...

    if (!$p.$NA())
    {
        $p.$oA();
    }

    Application.quitting += delegate()
    {
        $IA.$wb(true);
        SteamAPI.Shutdown();
    };

    Debug.unityLogger.Log("After ApplicationHelper");
}
  • 中央の条件分岐が怪しい。$p.$oA() の定義にジャンプすると、ログに出力されていた QuitOrThrow called の発生源が見つかる。
public static void $oA()
{
    Debug.LogError("QuitOrThrow called");
    Application.Quit(0);
    Environment.Exit(0);
}
  • 条件式部分の $p.$NA() は SteamAPI の初期化処理である。失敗すれば例外を発生させ、成功すれば true を返す。
public static bool $NA()
{
    if ($p.$Af)
    {
        $p.$Bb();
        if (SteamAPI.RestartAppIfNecessary($p.$Te))
        {
            $p.$oA();
        }
        if (!SteamAPI.Init())
        {
            throw new Exception("SteamAPI failed to initialize");
        }
        if (!Packsize.Test())
        {
            throw new Exception("Packsize Test returned false, the wrong version of Steamworks.NET is being run in this platform.");
        }
        if (!DllCheck.Test())
        {
            throw new Exception("DllCheck Test returned false, One or more of the Steamworks binaries seems to be the wrong version.");
        }
        $p.$Af = true;
    }
    return true;
}

改変例

  • 上述の $p.$NA() が常に true を返すよう改変してみる。冒頭の if 分岐を通らなければ、そもそも SteamAPI の初期化自体行わないので、条件式 $p.$Af を否定してみる。

  • 該当行で右クリックし、Edit IL Instructions を選択。

1 ldsfld bool $b.$p::$Af
2 brtrue.s 24 ldc.i4.1
...
24 ldc.i4.1
25 ret

  • brtrue.s はスタックの一番上にある値が true なら、指定された場所へジャンプする命令である。条件を反転したい場合は brfalse.s に置き換えればよい。

  • File -> Save Module から改変した DLL をエクスポートできる。エクスポート後、元の Game.dll を置き換え、if-app.exe を直接起動すると、Steam なしで起動することに成功する。
