10:T150e,<h1>前提条件</h1>
<ul>
<li>dnSpy v6.1.8 (.NET)</li>
</ul>
<h1>背景</h1>
<ul>
<li>
<p>インストールディレクトリ直下の <code>if-app.exe</code> を直接起動すると、Steam 側に「ゲーム設定が利用できません」とのエラーメッセージが表示され、ゲーム自体は応答なしとなる。</p>
</li>
<li>
<p><code>%USERPROFILE%\AppData\LocalLow\lowiro\if-app\Player.log</code> の末尾を見ると、Unity / DirectX / FMOD 側の初期化処理は正常に完了しており、ゲーム側の初期化処理で終了していることが確認できる。</p>
</li>
</ul>
<pre><code>Starting up. Version:0.3.1
Before ApplicationHelper
[FMOD] InitCore successful
[FMOD] InitCore successful
QuitOrThrow called
</code></pre>
<ul>
<li>
<p><code>if-app_Data\Plugins\x86_64\steam_api64.dll</code>、<code>if-app_Data\Managed\com.rlabrecque.steamworks.net.dll</code> が存在する。これは Steamworks.NET を利用する構成である。</p>
</li>
<li>
<p><code>if-app_Data\Managed</code> 以下の DLL が Steamworks の初期化を行っているのだと考えられるので、とりあえず、<code>Game.dll</code> を dnSpy で解析してみる。</p>
</li>
</ul>
<h1>解析</h1>

<h2>改変例</h2>
<ul>
<li>
<p>上述の <code>$p.$NA()</code> が常に <code>true</code> を返すよう改変してみる。冒頭の <code>if</code> 分岐を通らなければ、そもそも SteamAPI の初期化自体行わないので、条件式 <code>$p.$Af</code> を否定してみる。</p>
</li>
<li>
<p>該当行で右クリックし、<code>Edit IL Instructions</code> を選択。</p>
</li>
</ul>
<pre><code>1 ldsfld bool $b.$p::$Af

<ul>
<li>

</li>
<li>
<p>File -> Save Module から改変した DLL をエクスポートできる。エクスポート後、元の <code>Game.dll</code> を置き換え、<code>if-app.exe</code> を直接起動すると、Steam なしで起動することに成功する。</p>
</li>
