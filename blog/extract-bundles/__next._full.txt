10:Tecc,<h1>前提条件</h1>
<ul>
<li>公式にバンドルが配信されているバージョンであること</li>
</ul>
<h1>How to extract</h1>
<ul>
<li>
<p>現在、配信されるバンドルファイルは <code>100MB</code> ごとに分割されており、それぞれ <code>6.14.11_0.bundle</code> <code>6.14.11_1.bundle</code> ... と命名され、<code>/data/data/moe.low.arc/files/dltemp</code> に配置される。ただし、ダウンロード中の場合は <code>.bundle.tmp</code></p>
</li>
<li>
<p>バンドルのメタデータを含む <code>6.14.11.json</code> も必要。</p>
</li>
<li>
<p>ゲーム内で上記のファイルをダウンロードし終えると、ファイルの検証に移り、これらのファイルはすぐに削除されてしまう。（アプリ本体にマージされる）</p>
</li>
<li>
<p><strong>つまり、最終分割 <code>6.14.11_N.bundle</code> のダウンロードが完了した瞬間にアプリを強制終了すればよい。</strong></p>
</li>
<li>
<p><code>N</code> の値はゲーム内メッセージで確認できるファイルサイズを <code>100MB</code> で割った値により計算できる。（例： <code>853.33MB</code> -> <code>N = 8</code>）</p>
</li>
</ul>
<h1>Extract bundles!</h1>
<p><code>/data/data/</code> へのアクセスは非 root 端末では禁止されている。そのため、Android Studio Emulator を使用する。
Servicesには <code>Google APIs</code>を、System Image に <code>arm64-v8a</code> をサポートするものを選択する。</p>
<h2>Script for extract</h2>
<ul>
<li>watch.sh</li>
</ul>
<pre><code class="hljs language-bash"><span class="hljs-meta">#!/system/bin/sh</span>

<span class="hljs-keyword">while</span> <span class="hljs-literal">true</span>
<span class="hljs-keyword">do</span>
