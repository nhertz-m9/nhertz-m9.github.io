【moe.low.arc v6.14.11】Bundle を抽出する

June 14, 2026

前提条件

  • 公式にバンドルが配信されているバージョンであること

How to extract

  • 現在、配信されるバンドルファイルは 100MB ごとに分割されており、それぞれ 6.14.11_0.bundle 6.14.11_1.bundle ... と命名され、/data/data/moe.low.arc/files/dltemp に配置される。ただし、ダウンロード中の拡張子は .bundle.tmp

  • バンドルのメタデータを含む 6.14.11.json も必要。

  • ゲーム内で上記のファイルをダウンロードし終えると、ファイルの検証に移り、これらのファイルはすぐに削除されてしまう。（アプリ本体にマージされる）

  • これを回避するには、すべての 6.14.11_N.bundle をダウンロードし終えた直後にアプリを強制終了すればよい。

  • N の値はゲーム内メッセージで確認できるファイルサイズを 100MB で割った値により計算できる。（例： 853.33MB -> N = 8）

Extract bundles!

/data/data/ へのアクセスは非 root 端末では禁止されている。そのため、Android Studio Emulator を使用する。 Servicesには Google APIs を、System Image に arm64-v8a をサポートするものを選択する。

Script

  • watch.sh (N = 8)
#!/system/bin/sh

PACKAGE="moe.low.arc"
TARGET="/data/data/${PACKAGE}/files/dltemp"

while true
do
    [ -f "${TARGET}/6.14.11_0.bundle" ] &&
    [ -f "${TARGET}/6.14.11_1.bundle" ] &&
    # ...
    [ -f "${TARGET}/6.14.11_8.bundle" ] && {
        am force-stop "$PACKAGE"
        exit 0
    }
done
  • エミュレータへ転送し、実行。
adb root # if needed
adb push watch.sh /data/local/tmp/
adb shell

# emulator shell
su
chmod 755 /data/local/tmp/watch.sh
/data/local/tmp/watch.sh
  • この状態でゲームを起動し、バンドルをダウンロードすると、検証が始まる前にゲームが落ちるので、目的のファイルを抽出できる。
adb pull /data/data/moe.low.arc/files/dltemp

Congratulations!

Appendix: .bundle -> .cb

  • Bundler をクローンし、main.py を入手する。

  • ./bundles/ に dltemp/ 以下のファイルがコピーされているとする。

python main.py d -i ./bundles/6.14.11.bundle -m ./bundles/6.14.11.json 
# -> ./output
python main.py b -i output -o ./rebundled -av 6.14.11 -bv 6.14.11 
# .cb files generated
