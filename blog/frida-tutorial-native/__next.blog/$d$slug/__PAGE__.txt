<h1>Interceptor, Stalker</h1>
<ul>
<li>
<p><a href="https://frida.re/docs/javascript-api/#interceptor">Interceptor</a> を使用して特定の関数呼び出しを傍受できる。特定 API 呼び出しの引数や戻り値、呼び出し元の確認、関数の置き換えなど（<code>Interceptor.replace</code>）を行う。</p>
</li>
<li>
<p><a href="https://frida.re/docs/javascript-api/#stalker">Stalker</a> によって、あるスレッドが実際にどのようなコード経路を通ったかを命令レベルで追跡する。<code>Interceptor</code> よりも CPU 負荷が高く、ログも大量であるため、長時間のトレースには向かない。</p>
</li>
</ul>
