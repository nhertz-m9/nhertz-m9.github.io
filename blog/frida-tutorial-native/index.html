【Frida】ネイティブライブラリを解析する

August 26, 2026
  • 基本的な手順は 【frida-server】エミュレータ上で動的解析 を参照せよ。

前提条件

  • Android Emulator (Android 15.0 ("VanillaIceCream") | x86_64)
  • frida-server-17.7.3-android-x86_64
  • UnCrackable-Level3

Interceptor, Stalker

  • Interceptor を使用して特定の関数呼び出しを傍受できる。特定 API 呼び出しの引数や戻り値、呼び出し元の確認、関数の置き換えなど（Interceptor.replace）を行う。

  • Stalker によって、あるスレッドが実際にどのようなコード経路を通ったかを命令レベルで追跡する。Interceptor よりも CPU 負荷が高く、ログも大量であるため、長時間のトレースには向かない。

Interceptor.attach(ptr, {
    onEnter(args) {
        console.log("[+] called");

        Stalker.follow(this.threadId, {
            events: {
                call: true
            },
            onCallSummary(summary) {
            }
        });
    },
    onLeave(ret) {
        Stalker.unfollow(this.threadId);
        Stalker.garbageCollect();
    }
});

Ghidra で静的解析

  • Search -> Program Text から All Fields を対象に frida を検索してみると、s_frida_00103b62 として文字列 frida が見つかる。

  • xref から、その参照元である FUN_001037c0 に辿り着く。

  • 大まかに処理を追っていくと、関数冒頭で /proc/self/maps を開き、その内容を少し先の fgets で acStack_238 に格納している。strstr で acStack_238 に文字列 frida が含まれるかを判定し、含まれる場合はループから抜けて強制終了する。

  • Frida の agent が注入されると、プロセスの memory map に Frida 関連の名前が現れることを利用した、一般的な Frida 検知だ。

  • 今回は、これを回避するにあたって、Interceptor で strstr の呼び出しを監視し、第二引数 strSearch に frida を含む場合に戻り値を 0 に書き換えるという方法をとってみる。

char *strstr(
   const char *str,
   const char *strSearch
);
  • hook.js
var strstr = Process.getModuleByName("libc.so").findExportByName("strstr");
Interceptor.attach(strstr, {

    onEnter: function(args) {

        this.target = args[1];
        this.frida = 0;

        var target = this.target.readUtf8String();

        if (target.includes("frida")) {
            this.frida = 1;
        }
    },
    onLeave: function(ret) {

        if (this.frida === 1) {
            ret.replace(0);
        }
        return ret;
    }
});
  • this.frida でこの呼び出しが Frida を検知する目的かどうかを判断している。
frida -U -f owasp.mstg.uncrackable3 -l hook.js
  • 強制終了を回避することを確認。

キー検証をバイパス

  • 前回と同様に Java API を使って検証用の関数を探す。

  • public boolean CodeCheck.check_code(java.lang.String) が怪しい。

Java.perform(function () {
    const C = Java.use("sg.vantagepoint.uncrackable3.CodeCheck");

    C.check_code.overload("java.lang.String").implementation = function (s) {
        return true;
    };
