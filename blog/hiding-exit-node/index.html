【Whonix】SOCKS5 Proxy で Tor の ExitNode を秘匿する

June 15, 2026

前提条件

  • Oracle VirtualBox
  • Whonix 導入済み

目的

  • Tor の ExitNodes はリスト化されており、一部のサイトはこれを検知し、アクセスをブロックする。
  • そこで、ExitNode の後に追加でプロキシを挟むことにより、これを回避する。
  • Whonix では 9050 番ポートへ接続することで SOCKS5 プロキシを利用できる。

Setup OpenVPN

sudo apt update
sudo apt install openvpn

  • VPN Gate から任意の中継サーバを選択し、OpenVPN 用の設定ファイル .ovpn をダウンロード。 （例：vpngate_public-vpn-227.opengw.net_tcp_443.ovpn）

  • .ovpn を開き、以下の二項目を確認。protocol には tcp を指定し、proxy に socks-proxy を追記する。

# Specify the underlying protocol beyond the Internet.
proto tcp

# The HTTP/HTTPS proxy setting.
;http-proxy-retry
;http-proxy [proxy server] [proxy port]
socks-proxy 10.152.152.10 9050
  • 起動する
sudo openvpn --config vpngate_public-vpn-227.opengw.net_tcp_443.ovpn
  • BrowserLeaks へアクセスし、IP が プロキシサーバのものになっていることを確認する。

Congratulations!
