【Android】アプリの通信内容をハイジャックする

June 14, 2026

前提条件

  • mitmproxy が利用可能

SSL Proxying

以下、PC（プロキシサーバ）のIPが 192.168.0.16 であるとする。

  • username/.mitmproxy/ に生成された mitmproxy-ca-cert.cer をクライアント端末へコピーし、ユーザー証明書としてインストールしておく。
mitmproxy --listen-host 0.0.0.0 -p 8888

VPN

  • VProxid をインストールし、プロファイルを作成する。
Server: 192.168.0.16
Server Port: 8888
Server Type: http
Enable Auth: OFF
Apps: (select target apps)
  • mitmproxy 側で選択したアプリの通信内容が見えることを確認する。

URL Mapping

URL Mapping によって、プロキシで受け取ったリクエストをどの宛先へ転送するかを対応付ける。 今回は、ローカルのモックサーバ 192.168.0.16:7777 へ転送し、偽のレスポンスを返してみる。mitmproxyでは、Python スクリプトを利用することで実装できる。

Python Script

  • map.py
from mitmproxy import http
import requests

REWRITE_SERVER = "http://192.168.0.16:7777"

def request(flow: http.HTTPFlow):
    try:
        if "api-v1.app.com" not in flow.request.pretty_host:
            return
        
        url = REWRITE_SERVER + flow.request.path

        r = requests.request(
            method=flow.request.method,
            url=url,
            headers=dict(flow.request.headers),
            data=flow.request.raw_content,
            timeout=10
        )

        flow.response = http.Response.make(
            r.status_code,
            r.content,
            dict(r.headers)
        )
        
    except Exception as e:
        print(e)

mitmproxy --listen-host 0.0.0.0 -p 8888 -s map.py
