<h1>SSL Proxying</h1>
<ul>
<li>TLS を終端させる場合、<code>~/.mitmproxy/</code> に生成されたルート証明書 <code>mitmproxy-ca-cert.cer</code> をクライアント端末へコピーし、ユーザー証明書としてインストールしておく。</li>
</ul>
<pre><code class="hljs language-bash">mitmproxy --listen-host 0.0.0.0 -p 8080
</code></pre>
<h2>Run on WSL2</h2>
<ul>
<li><code>.wslconfig</code> に追記、ミラーモードの設定を行う。</li>
</ul>
<pre><code>[wsl2]
networkingMode=mirrored
</code></pre>
<pre><code>wsl --shutdown
bash
ip addr
</code></pre>
<ul>
<li>必要に応じてファイアウォールを開放する。</li>
</ul>
<pre><code>New-NetFirewallRule `
  -DisplayName "WSL mitmproxy" `
  -Direction Inbound `
  -Protocol TCP `
  -LocalPort 8080 `
  -Action Allow
</code></pre>
<h1>VPN</h1>
<ul>
<li><a href="https://f-droid.org/en/packages/com.github.dyhkwong.sagernet/">Exclave</a> をインストールし、プロファイルを作成する。</li>
</ul>
<pre><code>Server Type: HTTP
Server: 192.168.0.16
Server Port: 8080
</code></pre>
<ul>
<li>警告が出る場合、<code>Settings</code> -> <code>Protocol settings</code> -> <code>Security tips</code> を無効にする。</li>
<li>VPN を起動し、mitmproxy 側で通信内容が見えることを確認する。</li>
</ul>
<h1>URL Mapping</h1>
<p>URL Mapping によって、プロキシで受け取ったリクエストをどの宛先へ転送するかを対応付ける。
今回は、ローカルのモックサーバ <code>192.168.0.16:7777</code> へ転送し、偽のレスポンスを返してみる。mitmproxy では、Python スクリプトを利用することで実装できる。</p>
