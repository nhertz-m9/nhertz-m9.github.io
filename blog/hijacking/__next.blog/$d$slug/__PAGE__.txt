<ul>
<li><a href="https://learn.microsoft.com/en-us/windows/wsl/install">Windows Subsystem for Linux 2</a></li>

<h1>SSL Proxying with mitmproxy</h1>
<h2>Install on WSL2</h2>
<ul>
<li>公式配布のバイナリを展開し、パスを通しておく。</li>
</ul>
<pre><code class="hljs language-bash"><span class="hljs-built_in">cd</span> /tmp

wget https://downloads.mitmproxy.org/12.1.1/mitmproxy-12.1.1-linux-x86_64.tar.gz

tar xzf mitmproxy-12.1.1-linux-x86_64.tar.gz

<span class="hljs-built_in">sudo</span> <span class="hljs-built_in">mv</span> mitmproxy /usr/local/bin/
<span class="hljs-built_in">sudo</span> <span class="hljs-built_in">mv</span> mitmdump /usr/local/bin/
<span class="hljs-built_in">sudo</span> <span class="hljs-built_in">mv</span> mitmweb /usr/local/bin/
</code></pre>
<h2>Run on WSL2</h2>
<ul>
<li><code>.wslconfig</code> に追記、ミラーモードの設定を行う。</li>
</ul>
<pre><code>[wsl2]
networkingMode=mirrored
</code></pre>
<pre><code>wsl --shutdown
bash
ip addr
</code></pre>
<ul>
<li>必要に応じてファイアウォールを開放する。</li>
</ul>
<pre><code>New-NetFirewallRule `
  -DisplayName "WSL mitmproxy" `
  -Direction Inbound `
  -Protocol TCP `
  -LocalPort 8080 `
  -Action Allow
</code></pre>
<ul>
<li>TLS を終端させるには、初回起動時に <code>~/.mitmproxy/</code> に生成されたルート証明書 <code>mitmproxy-ca-cert.cer</code> をクライアント端末へコピーし、ユーザー証明書としてインストールしておく必要がある。</li>
</ul>
<pre><code class="hljs language-bash">mitmproxy --listen-host 0.0.0.0 -p 8080
</code></pre>
<ul>
<li><code>Shift</code> + <code>F</code> で Flowing 切り替え。</li>
</ul>
<h1>VPN</h1>
<ul>
<li><a href="https://f-droid.org/en/packages/com.github.dyhkwong.sagernet/">Exclave</a> をインストールし、プロファイルを作成する。</li>
</ul>
<pre><code>Server Type: HTTP
Server: 192.168.0.16
Server Port: 8080
</code></pre>
<ul>
<li>警告が出る場合、<code>Settings</code> -> <code>Protocol settings</code> -> <code>Security tips</code> を無効にする。</li>
<li>VPN を起動し、mitmproxy 側で通信内容が見えることを確認する。</li>
</ul>
<h1>URL Mapping</h1>
<p>受け取ったリクエストを特定の宛先へ転送する。</p>
<ul>
<li>今回は、ローカルのモックサーバ <code>192.168.0.16:7777</code> へ転送し、偽のレスポンスを返してみる。mitmproxy では、Python で実装できる。</li>
</ul>
