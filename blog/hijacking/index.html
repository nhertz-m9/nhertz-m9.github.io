【Android】TLS 通信をハイジャックする

July 4, 2026

前提条件

  • Windows Subsystem for Linux 2
  • mitmproxy
  • Exclave

SSL Proxying with mitmproxy

Install on WSL2

  • 公式配布のバイナリを展開し、パスを通しておく。
cd /tmp

wget https://downloads.mitmproxy.org/12.1.1/mitmproxy-12.1.1-linux-x86_64.tar.gz

tar xzf mitmproxy-12.1.1-linux-x86_64.tar.gz

sudo mv mitmproxy /usr/local/bin/
sudo mv mitmdump /usr/local/bin/
sudo mv mitmweb /usr/local/bin/

Run on WSL2

  • .wslconfig に追記、ミラーモードの設定を行う。
[wsl2]
networkingMode=mirrored

wsl --shutdown
bash
ip addr
  • 必要に応じてファイアウォールを開放する。
New-NetFirewallRule `
  -DisplayName "WSL mitmproxy" `
  -Direction Inbound `
  -Protocol TCP `
  -LocalPort 8080 `
  -Action Allow
  • TLS を終端させるには、初回起動時に ~/.mitmproxy/ に生成されたルート証明書 mitmproxy-ca-cert.cer をクライアント端末へコピーし、ユーザー証明書としてインストールしておく必要がある。
mitmproxy --listen-host 0.0.0.0 -p 8080
  • Shift + F で Flowing 切り替え。

VPN

  • Exclave をインストールし、プロファイルを作成する。
Server Type: HTTP
Server: 192.168.0.16
Server Port: 8080
  • 警告が出る場合、Settings -> Protocol settings -> Security tips を無効にする。
  • VPN を起動し、mitmproxy 側で通信内容が見えることを確認する。

URL Mapping

受け取ったリクエストを特定の宛先へ転送する。

  • 今回は、ローカルのモックサーバ 192.168.0.16:7777 へ転送し、偽のレスポンスを返してみる。mitmproxy では、Python で実装できる。

Python Script

  • map.py
from mitmproxy import http
import requests

TARGET = "example.app.com"
REWRITE_SERVER = "http://192.168.0.16:7777"

def request(flow: http.HTTPFlow):
    try:
        if TARGET not in flow.request.pretty_host:
            return
        
        url = REWRITE_SERVER + flow.request.path

        r = requests.request(
            method=flow.request.method,
            url=url,
            headers=dict(flow.request.headers),
            data=flow.request.raw_content,
            timeout=10
        )

        flow.response = http.Response.make(
            r.status_code,
            r.content,
            dict(r.headers)
        )
        
    except Exception as e:
        print(e)

mitmproxy --listen-host 0.0.0.0 -p 8080 -s map.py
