Debian on VirtualBox で aircrack-ng を使う

July 15, 2026

前提条件

  • Oracle VirtualBox
  • モニターモードに対応する外付け Wi-Fi アダプタ（本記事では ALFA AWUS036ACH を使用する）

Windows

  • ALFA AWUS036ACH Driver & Support Page より、対応する Windows のドライバをダウンロード。(Windows 11/10: Alfa AWUS036AC/AWUS036ACH/AWUS036EAC Windows 11/10/8/7)

Setup Debian on VirtualBox

  • Settings -> USB -> Enable USB Controller
  • USB 3.0(xHCI) を選択し、Realtek 802.11n NIC を追加。

Install driver

git clone https://github.com/morrownr/8812au-20210820.git
cd 8812au-20210820

sudo ./install-driver.sh
  • kernel header cannot be found Install Kernel Headers on Kali Linux を参照。
  • 指示に従い再起動後、無線 LAN アダプタが認識されていることを確認する。
ip link
  • ホスト OS のアダプタを使用しない場合、Settings -> Network -> Enable Network Adapter を切っておく。

Installation

sudo apt update
sudo apt install aircrack-ng

aircrack-ng

Usages

sudo airmon-ng check kill
sudo airmon-ng start [interface]

sudo airodump-ng [interface]
sudo airodump-ng --bssid [BSSID(access point)] -c [channel] [interface]

# `1` is the number of deauths to send, 0 means send them continuously
sudo aireplay-ng -0 1 -a [BSSID(access point)] -c [BSSID(station)] [interface]

sudo airmon-ng stop [interface]
systemctl restart NetworkManager
