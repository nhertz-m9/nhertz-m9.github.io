<ul>

<li>Arcaea 6.16.0 (xapk)</li>

<h1>APKの編集準備</h1>

<h1>SSL Pinning</h1>
<p><code>libcocos2dcpp.so</code> 内で独自の SSL Pinning が実装されているため、
<a href="https://codeshare.frida.re/@masbog/frida-android-unpinning-ssl/">Project: frida-android-unpinning-ssl</a> 等の汎用スクリプトは使用できない。</p>

<li>最低限のオプションを以下に示す。</li>

Function Start Search
Function Start Search After Code
</code></pre>
