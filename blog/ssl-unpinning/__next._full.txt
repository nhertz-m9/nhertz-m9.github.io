11:T13c3,<h1>前提条件</h1>
<ul>
<li>Android Sdk (apktool, zipalign, apksigner)</li>
<li>Arcaea 6.14.11 (apk/xapk)</li>
<li>Ghidra</li>
</ul>
<h1>APKの編集準備</h1>
<ul>
<li>分割 apk の形で配布されている。再ビルド時にすべての分割で署名を統一する必要がある。</li>
</ul>
<pre><code class="hljs language-bash">apktool d <span class="hljs-string">"Arcaea.xapk"</span>
<span class="hljs-built_in">cd</span> <span class="hljs-string">"Arcaea.xapk.out/unknown"</span>

<span class="hljs-built_in">cd</span> <span class="hljs-string">"./config.arm64_v8a/lib/arm64-v8a"</span> <span class="hljs-comment"># you can find libcocos2dcpp.so here</span>
</code></pre>
<h1>SSL Pinning</h1>
<p><code>libcocos2dcpp.so</code> 内で独自の SSL Pinning が実装されているため、
<a href="https://codeshare.frida.re/@masbog/frida-android-unpinning-ssl/">Project: frida-android-unpinning-ssl</a> 等の汎用スクリプトは使用できない。</p>
<h2>Ghidraでパッチを当てる</h2>
<ul>
<li>Ghidra で <code>libcocos2dcpp.so</code> を開き、Analyze を実行。</li>
<li>Search -> Scalar Search で <code>408(0x198)</code> を検索。</li>
<li><code>add x0, x0</code> でフィルタリングし、ヒットした数個の命令へジャンプし、それぞれをデコンパイルする。(Window -> Decompile)</li>
<li>以下のようなデコンパイル結果になっている関数を見つける。（今回は <code>SUB_009ffee4</code> が該当する。）</li>
</ul>
<pre><code class="hljs language-c"><span class="hljs-type">void</span> <span class="hljs-title function_">UndefinedFunction_009ffee4</span><span class="hljs-params">(<span class="hljs-type">long</span> param_l, undefined8 param_2)</span> {

    <span class="hljs-comment">// extra 2 lines..</span>

<ul>
<li>この関数の <code>xref</code> から唯一の呼び出し元関数へジャンプし、該当する <code>BL</code> 命令を <code>NOP</code> する。(Right Click -> Patch Instruction)</li>
</ul>
<pre><code>BL SUB_009ffee4 -> NOP
</code></pre>
<ul>
<li>Search -> Scalar Search で <code>488(0x1e8)</code> を検索。</li>
<li>上と同様の手順で以下のような関数を見つける</li>

<h2>APKを再ビルドする</h2>
<ul>
<li>パッチを当てた <code>libcocos2dcpp.so</code> で、元のファイルを上書きする。</li>
<li>署名用のキーストアを作っておく。<code>./my.keystore</code></li>
</ul>
<pre><code class="hljs language-bash">apktool b <span class="hljs-string">"moe.low.arc"</span> --use-aapt2 -o <span class="hljs-string">"moe.low.arc.apk"</span>

<span class="hljs-comment"># as well as other split apk folders...</span>
